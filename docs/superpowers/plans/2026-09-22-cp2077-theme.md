# CP2077 全站 UI 重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将现有 SaaS 深色风格 UI 全站重构为 CP2077 赛博朋克风格（切角边框、红青撞色、Rajdhani 字体、扫描线、大写标题）。

**Architecture:** antd 深度换肤 + Cyber 原语层（方案 A）。三层实现：主题 token（theme.tsx）、原语组件（components/cyber/）、全局样式（global.less）。页面逻辑零改动，仅动外观层。

**Tech Stack:** Umi Max + antd v5 + Less + Rajdhani 字体（本地打包，OFL 许可）

**Spec:** docs/superpowers/specs/2026-09-22-cp2077-theme-design.md

## Global Constraints

- 色板（精确值，不得偏离）：bgLayout `#0E0E17`、bgContainer `#161616`、bgElevated `#1A1A26`、red `#F75049`、cyan `#5EF6FF`、green `#1DED83`、yellow `#F0B537`、orange `#FB932E`、blue `#2570D4`、purple `#9D2BF5`、contrast `#D6D0D0`
- 切角 clip-path 常量：`polygon(12px 0, 100% 0, 100% calc(100% - 12px), calc(100% - 12px) 100%, 0 100%, 0 12px)`（左上/右下双切角）
- 字体：Rajdhani 本地打包（禁 CDN）；回退栈 `-apple-system, 'Segoe UI', 'Microsoft YaHei', sans-serif`；Blender Pro 用 Rajdhani Bold 替代
- 语义映射：safe→green、caution→yellow、keep→cyan、never→red
- **Widget 页（src/pages/Widget/）完全不动**；扫描线覆盖层必须挂在布局根节点（`.cyber-app`）而非 body，避免影响 Widget 窗口
- 旧名 `figmaColors` 以临时别名保留至 Task 7 才删除；`figmaTheme` 直接更名为 `cyberTheme`（仅 app.tsx 引用）
- **同一文件只发一次 SearchReplace**（合并 import 与代码改动）；每次编辑后立即编译检查：`npx tsc --noEmit --pretty 2>&1 | Select-String "<目录>"`
- 已知既有编译错误（忽略，非本次引入）：app.tsx 的 `location` 类型、pages/404 的 `back` 类型、setup/theme.tsx 的 antd 自定义 token 类型
- 每个任务结束必须单独 git commit

```tsx
import { Button } from 'antd';
import type { ButtonProps } from 'antd';
import type { CSSProperties, MouseEvent, ReactNode } from 'react';
import './cyber.less';

interface CyberCardProps {
  /** cyan：青描边（默认）；red：红描边 */
  variant?: 'cyan' | 'red';
  /** DOM id（页面内滚动定位用，如 Cleanup 的 group-* 锚点） */
  id?: string;
  /** 左侧竖条（对应 Figma Card/Frame-M） */
  stripe?: boolean;
  /** 扫描线纹理覆盖 */
  scan?: boolean;
  onClick?: (e: MouseEvent<HTMLDivElement>) => void;
  className?: string;
  style?: CSSProperties;
  children?: ReactNode;
}

/** CP2077 切角面板：外层主色做"描边"，内层内缩 1px 同 clip-path 做底色 */
export function CyberCard({
  variant = 'cyan',
  id,
  stripe,
  scan,
  onClick,
  className,
  style,
  children,
}: CyberCardProps) {
  const cls = [
    'cyber-card',
    `cyber-card-${variant}`,
    stripe ? 'cyber-card-stripe' : '',
    scan ? 'cyber-card-scan' : '',
    className ?? '',
  ]
    .filter(Boolean)
    .join(' ');
  return (
    <div id={id} className={cls} style={style} onClick={onClick}>
      <div className="cyber-card-inner">{children}</div>
    </div>
  );
}

interface CyberButtonProps extends ButtonProps {
  variant?: 'cyan' | 'red';
}

/** CP2077 切角轮廓按钮（基于 antd Button，仅覆盖外观） */
export function CyberButton({ variant = 'cyan', className, ...rest }: CyberButtonProps) {
  return (
    <Button
      {...rest}
      className={`cyber-btn cyber-btn-${variant} ${className ?? ''}`.trim()}
    />
  );
}

interface SectionTitleProps {
  /** 红色发光效果 */
  glow?: boolean;
  style?: CSSProperties;
  children?: ReactNode;
}

/** Rajdhani SemiBold 大写标题；glow 时红色 + 模糊光晕 */
export function SectionTitle({ glow, style, children }: SectionTitleProps) {
  return (
    <div className={`cyber-title${glow ? ' cyber-title-glow' : ''}`} style={style}>
      {children}
    </div>
  );
}

/** 红色分隔线（对应 Figma Separators：2px、30% 透明度、左端斜切缺口） */
export function CyberDivider({ style, className }: { style?: CSSProperties; className?: string }) {
  return <div className={`cyber-divider ${className ?? ''}`.trim()} style={style} />;
}
```
